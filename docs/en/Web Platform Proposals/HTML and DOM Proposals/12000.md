# [FEE-12000] HTML & DOM Proposals Overview

:::warning Web Platform Proposals
Articles in the 10000-19999 range cover features that are not yet stable across all major browsers. When a feature ships stable, its article graduates to the appropriate 0-9999 category.
:::

This track covers HTML Living Standard additions and new DOM APIs from WHATWG and W3C that are in active development or have shipped in some but not all major browsers.

## Tracks in this range

| Range | Topic |
|-------|-------|
| 12001-12099 | New HTML elements and attributes |
| 12100-12199 | DOM API additions and event model changes |
| 12200-12299 | Navigation and routing APIs |
| 12300-12399 | Performance and loading APIs |
| 12400-12499 | Security and privacy APIs |
| 12500-12999 | Reserved |

## Graduation

When a feature ships in all major browsers without flags, its article moves to HTML & Semantic Markup (100-199) or Browser APIs & Web Platform (400-499) depending on topic.
