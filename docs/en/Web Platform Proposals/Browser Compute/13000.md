# [FEE-13000] Browser Compute Overview

:::warning Web Platform Proposals
Articles in the 10000-19999 range cover features that are not yet stable across all major browsers. When a feature ships stable, its article graduates to the appropriate 0-9999 category.
:::

This track covers GPU and ML compute APIs exposed to the browser: WebGPU and WebNN. These APIs give web applications direct access to hardware accelerators for graphics rendering and machine learning inference.

## Tracks in this range

| Range | Topic |
|-------|-------|
| 13001-13099 | WebGPU: device model, pipelines, buffers |
| 13100-13199 | WebGPU: compute shaders, WGSL |
| 13200-13299 | WebNN: graph building, operator API |
| 13300-13399 | Integration patterns (WebGPU + WebAssembly) |
| 13400-13999 | Reserved |

## Graduation

WebGPU has shipped in Chrome and Safari. When Firefox ships it and all three engines are stable, articles graduate to Browser APIs & Web Platform (400-499).
