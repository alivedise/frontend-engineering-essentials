# [FEE-14000] WebAssembly Proposals Overview

:::warning Web Platform Proposals
Articles in the 10000-19999 range cover features that are not yet stable across all major browsers. When a feature ships stable, its article graduates to the appropriate 0-9999 category.
:::

This track covers proposals from the WebAssembly working group (Bytecode Alliance / W3C WebAssembly CG) that are standardized or in active development but not yet universally shipped.

## Tracks in this range

| Range | Topic |
|-------|-------|
| 14001-14099 | WASM GC (garbage collection for reference types) |
| 14100-14199 | WASM Component Model |
| 14200-14299 | WASI (WebAssembly System Interface) |
| 14300-14399 | Threads, SIMD, exception handling |
| 14400-14499 | WASM + JS interop patterns |
| 14500-14999 | Reserved |

## Graduation

Proposals graduate to Browser APIs & Web Platform (400-499) when they ship in Chrome, Firefox, and Safari without flags. WASM GC has already shipped in all three engines and is a near-term graduation candidate.
