# [FEE-11000] CSS Experimental Overview

:::warning Web Platform Proposals
Articles in the 10000-19999 range cover features that are not yet stable across all major browsers. When a feature ships stable, its article graduates to the appropriate 0-9999 category.
:::

This track covers CSS specifications that are in active development: features behind browser flags, available in one engine only, or defined in a working draft that has not yet reached Candidate Recommendation.

## Tracks in this range

| Range | Topic |
|-------|-------|
| 11001-11099 | Layout & positioning proposals |
| 11100-11199 | Animation & scroll-linked effects |
| 11200-11299 | CSS extensibility (Houdini worklets) |
| 11300-11399 | Custom properties & typed values |
| 11400-11499 | Scoping & specificity proposals |
| 11500-11999 | Reserved |

## Graduation

When a feature reaches Candidate Recommendation and ships in all major browsers without flags, its article moves to the CSS & Layout Systems category (200-299).
