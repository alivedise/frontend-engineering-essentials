# [FEE-11000] CSS 實驗性功能概覽

:::warning Web Platform Proposals
10000-19999 範圍內的文章涵蓋尚未在所有主要瀏覽器中穩定的功能。當功能正式穩定後，文章將移至對應的 0-9999 分類。
:::

本軌道涵蓋正在積極開發中的 CSS 規格：瀏覽器旗標後的功能、僅在單一引擎中可用的功能，或尚未達到候選推薦狀態的工作草稿功能。

## 此範圍的軌道

| 範圍 | 主題 |
|------|------|
| 11001-11099 | 版面與定位提案 |
| 11100-11199 | 動畫與捲動連結效果 |
| 11200-11299 | CSS 擴充性（Houdini worklets） |
| 11300-11399 | 自訂屬性與型別值 |
| 11400-11499 | 範疇與特異性提案 |
| 11500-11999 | 保留 |

## 畢業機制

當功能達到候選推薦狀態並在所有主要瀏覽器中無旗標出貨後，其文章將移至 CSS & Layout Systems 分類（200-299）。
