# [FEE-12000] HTML & DOM 提案概覽

:::warning Web Platform Proposals
10000-19999 範圍內的文章涵蓋尚未在所有主要瀏覽器中穩定的功能。當功能正式穩定後，文章將移至對應的 0-9999 分類。
:::

本軌道涵蓋 WHATWG 和 W3C 正在積極開發或已在部分瀏覽器中出貨的 HTML Living Standard 新增內容和新 DOM API。

## 此範圍的軌道

| 範圍 | 主題 |
|------|------|
| 12001-12099 | 新 HTML 元素與屬性 |
| 12100-12199 | DOM API 新增與事件模型變更 |
| 12200-12299 | 導航與路由 API |
| 12300-12399 | 效能與載入 API |
| 12400-12499 | 安全與隱私 API |
| 12500-12999 | 保留 |

## 畢業機制

當功能在所有主要瀏覽器中無旗標出貨後，其文章將移至 HTML & Semantic Markup（100-199）或 Browser APIs & Web Platform（400-499），依主題而定。
