# [FEE-14000] WebAssembly 提案概覽

:::warning Web Platform Proposals
10000-19999 範圍內的文章涵蓋尚未在所有主要瀏覽器中穩定的功能。當功能正式穩定後，文章將移至對應的 0-9999 分類。
:::

本軌道涵蓋 WebAssembly 工作組（Bytecode Alliance / W3C WebAssembly CG）已標準化或正在積極開發，但尚未在所有瀏覽器中出貨的提案。

## 此範圍的軌道

| 範圍 | 主題 |
|------|------|
| 14001-14099 | WASM GC（參考型別垃圾回收） |
| 14100-14199 | WASM 元件模型 |
| 14200-14299 | WASI（WebAssembly 系統介面） |
| 14300-14399 | 執行緒、SIMD、例外處理 |
| 14400-14499 | WASM + JS 互通模式 |
| 14500-14999 | 保留 |

## 畢業機制

當提案在 Chrome、Firefox 和 Safari 中均無旗標出貨後，文章將移至 Browser APIs & Web Platform（400-499）。WASM GC 已在三大引擎中出貨，是近期畢業的候選項目。
