# [FEE-13000] 瀏覽器運算概覽

:::warning Web Platform Proposals
10000-19999 範圍內的文章涵蓋尚未在所有主要瀏覽器中穩定的功能。當功能正式穩定後，文章將移至對應的 0-9999 分類。
:::

本軌道涵蓋瀏覽器暴露的 GPU 與 ML 運算 API：WebGPU 和 WebNN。這些 API 讓網頁應用程式能直接存取硬體加速器，用於圖形渲染和機器學習推論。

## 此範圍的軌道

| 範圍 | 主題 |
|------|------|
| 13001-13099 | WebGPU：裝置模型、管線、緩衝區 |
| 13100-13199 | WebGPU：計算著色器、WGSL |
| 13200-13299 | WebNN：圖形建構、運算子 API |
| 13300-13399 | 整合模式（WebGPU + WebAssembly） |
| 13400-13999 | 保留 |

## 畢業機制

WebGPU 已在 Chrome 和 Safari 中出貨。當 Firefox 也出貨且三大引擎均穩定後，文章將移至 Browser APIs & Web Platform（400-499）。
