# [FEE-300] JavaScript 核心與執行環境總覽

:::info
本類別涵蓋瀏覽器中的 JavaScript 語言及其執行環境──執行模型、作用域規則、非同步模式和記憶體行為，這些是每位前端工程師 MUST 理解的基礎。
:::

## 背景

JavaScript 是瀏覽器原生支援的唯一程式語言。理解其執行模型至關重要──不僅是語法，還包括程式碼實際如何執行：單執行緒事件循環、閉包機制、原型鏈和記憶體生命週期。無論你使用哪個框架，這些基礎都適用。

## 使用情境

你正在除錯一個不固定復現的 bug：使用者的點擊處理器在 Chrome 正常觸發，在 Safari 卻無聲無息；一個資料請求在某個情境下運作正常，換個情境就靜默失敗。兩個問題的症狀如出一轍：在隔離環境中看起來正確的程式碼，在特定執行情境下卻行為異常。JavaScript 的執行模型──事件循環、呼叫堆疊、閉包、原型鏈──決定了這些互動的實際行為。理解執行模型，才是治本，而非只是治標。

## 為什麼這很重要

框架的抽象隱藏了執行環境。當出錯時──競態條件、記憶體洩漏、意外的 `this` 綁定──你需要理解引擎，而不是框架。理解執行環境的工程師能更快地除錯、撰寫更可預測的程式碼，並做出更好的架構決策。
