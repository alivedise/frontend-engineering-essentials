# [FEE-0] FEE 總覽

:::info
FEE（Frontend Engineering Essentials，前端工程精要）是一組與廠商無關的前端工程指南與最佳實踐。
:::

## 背景

前端工程涵蓋廣泛的領域──從 HTML 語意和 CSS 排版到元件架構、狀態管理和建置工具。工程師通常零散地學習這些概念，透過散落的部落格文章、特定框架的教學，或者痛苦的生產環境除錯。FEE 提供一組結構化、編號化的原則，建立完整的前端工程心智模型。

## 目的

- 建立前端工程討論的共同語彙
- 為常見的前端決策提供可操作的、廠商中立的指引
- 作為各層級工程師的學習資源
- 彌合「我會用框架」和「我理解平台」之間的差距

## 如何閱讀 FEE

每篇 FEE 遵循一致的結構：

- **背景** -- 為什麼這個原則重要
- **使用情境**（僅適用於 100–400 系列）——描述一個具體的產品情境，說明此 API 或特性是正確選擇的時機。
- **設計思維** -- 原則背後的心智模型與推理
- **最佳實踐** -- 可操作的規則（MUST / SHOULD / AVOID）
- **圖解** -- 有助理解的圖表
- **範例** -- 具體的、廠商中立的範例
- **常見錯誤** -- 應避免的反模式
- **相關 FEE** -- 其他原則的交叉引用
- **參考資料** -- 外部深入學習資源

## 類別

### 基礎層（0-499）

| 範圍 | 類別 | 焦點 |
|------|------|------|
| 0-99 | FEE 總覽 | 目的、詞彙表、元資料 |
| 100-199 | HTML 與語意標記 | 文件結構、無障礙語意、表單 |
| 200-299 | CSS 與排版系統 | 盒模型、flexbox、grid、響應式設計 |
| 300-399 | JavaScript 核心與執行環境 | 事件循環、閉包、原型、模組 |
| 400-499 | 瀏覽器 API 與 Web 平台 | DOM、fetch、儲存、workers、intersection observer |

### 架構與模式層（500-799）

| 範圍 | 類別 | 焦點 |
|------|------|------|
| 500-599 | 元件架構與設計模式 | 組合、插槽、響應式、關注點分離 |
| 600-699 | 狀態管理 | 本地與全域狀態、衍生狀態、同步模式 |
| 700-799 | 渲染與效能 | Virtual DOM、hydration、懶載入、核心 Web 指標 |

### 工具與系統層（800-999）

| 範圍 | 類別 | 焦點 |
|------|------|------|
| 800-899 | 建置工具與模組系統 | 打包器、tree-shaking、ESM、開發伺服器 |
| 900-999 | 設計系統與 UI 函式庫 | Token、主題化、元件庫、文件 |

### 工程實踐層（1000-1699）

| 範圍 | 類別 | 焦點 |
|------|------|------|
| 1000-1099 | 無障礙（a11y） | ARIA、螢幕閱讀器、鍵盤導航、色彩對比 |
| 1100-1199 | 測試策略 | 單元、整合、E2E、視覺回歸、無障礙測試 |
| 1200-1299 | 安全性 | XSS、CSP、CORS、子資源完整性、消毒 |
| 1300-1399 | 漸進式 Web 應用與離線 | Service workers、快取策略、應用程式清單 |
| 1400-1499 | 可觀測性與錯誤追蹤 | 錯誤邊界、日誌、RUM、source maps |
| 1500-1599 | CI/CD 與部署 | 建置管線、預覽部署、CDN、快取清除 |
| 1600-1699 | 開發者體驗與工具 | Lint、格式化、monorepo、開發伺服器、IDE 整合 |

## 文章元資料欄位

每篇 FEE 文章的 frontmatter 包含以下欄位：

| 欄位 | 值 | 說明 |
|------|----|------|
| `id` | 整數 | FEE 編號系統中的唯一文章編號 |
| `title` | 字串 | 文章標題 |
| `state` | `draft`、`placeholder` | 發布狀態 |
| `overview` | `true`（false 時省略） | 標記分類總覽頁；這些頁面沒有 `level` 欄位 |
| `level` | `entry`、`mid`、`senior`、`???` | 目標受眾難度。`entry` = 適合初級工程師；`mid` = 需要紮實基礎；`senior` = 進階深度。`???` = 待人工審查。 |
